# Contributing to Loft

Thank you for your interest in contributing to Loft. This document provides guidelines for contributing.

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Make your changes
4. Commit with a clear message (`git commit -m "Add your feature"`)
5. Push to your branch (`git push origin feature/your-feature`)
6. Open a Pull Request

## Code Standards

- Write clear, readable code
- Add tests for new functionality
- Follow existing code style and conventions
- Keep commits focused and atomic

## Reporting Issues

- Use GitHub Issues to report bugs
- Include steps to reproduce the issue
- Provide expected vs actual behavior
- Include relevant environment details

## Pull Request Process

1. Ensure your PR description clearly explains the changes
2. Link any related issues
3. Wait for a review before merging
